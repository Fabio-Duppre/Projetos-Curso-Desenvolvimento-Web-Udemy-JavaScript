# Projetos JavaScript

Repositório contendo três pequenos projetos desenvolvidos durante um curso introdutório de JavaScript.

Os projetos têm como objetivo explorar conceitos fundamentais de desenvolvimento web, utilizando JavaScript para implementar funcionalidades e interatividade em páginas HTML.

## Projetos

### 1. App Orçamento Pessoal

Aplicação web para gerenciamento básico de despesas pessoais.

**Funcionalidades:**

* Cadastro de despesas.
* Consulta de despesas cadastradas.
* Filtros por data, categoria, descrição e valor.
* Exclusão de registros.
* Armazenamento de informações utilizando LocalStorage.

**Tecnologias:** HTML5, CSS3, JavaScript e Bootstrap.

### 2. Calculadora JavaScript

Calculadora web com interface simples e operações matemáticas básicas.

**Funcionalidades:**

* Adição.
* Subtração.
* Multiplicação.
* Divisão.
* Limpeza do visor.
* Operações com números decimais.

**Tecnologias:** HTML5, CSS3, JavaScript e Bootstrap.

### 3. Mata Mosquito

Jogo desenvolvido em JavaScript no qual o jogador precisa acertar os mosquitos que aparecem aleatoriamente na tela antes que o tempo termine.

**Funcionalidades:**

* Três níveis de dificuldade: Normal, Difícil e HardCore.
* Posicionamento aleatório dos mosquitos.
* Variação no tamanho e na orientação dos personagens.
* Sistema de vidas.
* Cronômetro.
* Telas de vitória e fim de jogo.

**Tecnologias:** HTML5, CSS3, JavaScript e Bootstrap.

## Como executar

Os projetos não necessitam de instalação de dependências ou configuração de servidor.

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto desejado.

3. Abra o arquivo `index.html` diretamente no navegador.

**Observação:** O projeto Orçamento Pessoal utiliza o LocalStorage do navegador para armazenar os registros. Os projetos também utilizam recursos externos do Bootstrap, sendo necessária conexão com a internet para carregá-los corretamente.

## Objetivo

Reunir exercícios práticos desenvolvidos durante o aprendizado inicial de JavaScript, explorando manipulação do DOM, eventos, funções, classes, estruturas condicionais, armazenamento local e lógica de programação.
